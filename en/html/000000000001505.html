A/T Assembly Installation
Special Tools Required

Frame positioning guide pin
 070AG-SJAA100

Engine Support hanger
 AAR-T1256-J00
 This special tool (engine support hanger) is available  from Snap-on Tools International, LLC.
NOTE: Use fender covers to avoid damaging painted surfaces.
  1. Clean the ATF cooler as necessary.
  1. Install the clamp bracket.
  1. Install the torque converter (A) on the mainshaft (B) with the new O-ring (C).
  1. Install the 14 mm dowel pin (D) and 10 mm dowel pin (E) in the torque converter housing.
  1. Install the transmission lower mount with the new bolts.
  1. Place the transmission on the jack, and raise it to engine level.
  1. Attach the transmission to the engine, and install the transmission housing mounting bolts.
  1. Install the transmission housing mounting bolts.
  1. Install the transmission housing mounting bolts.
  1. Install the transmission housing mounting bolt (A) with a socket 22 mm in length and a torque wrench.
  1. Install the front mount bracket (B) with the new mounting bolts.
  1. Install the new set ring (A) on the intermediate shaft (B).
  1. Clean the areas where the intermediate shaft contacts the transmission (differential) with solvent or carburetor cleaner, and dry with compressed air. Apply intermediate shaft splines with ATF, then install the intermediate shaft, be sure not to allow dust or other foreign particles to enter the transmission.
  1. Install the exhaust manifold bracket (C) and heat shield (D).
  1. Install the new set ring (A) on the left driveshaft (B).
  1. Clean the areas where the left driveshaft contacts the transmission (differential) with solvent or carburetor cleaner, and dry with compressed air. Then install the left driveshaft, be sure not to allow dust or other foreign particles to enter the transmission. Turn the steering knuckle fully outward, and slide the driveshaft into the differential until you feel its set ring fully engage the side gear.
  1. Apply right driveshaft inboard-joint splines with the recommended grease.
  1. Slide the right driveshaft over the intermediate shaft splines until you feel the driveshaft fully engage the intermediate shaft set ring.
  1. Install the front subframe stop rubbers (A) on the front of the subframe (B), and support the front subframe with a wood piece (C) and a jack, and lift it up to body.
  1. Loosely install the new subframe mounting bolts (A), new rear stiffener mounting bolts (B), front stiffener mounting bolts (C), and front and rear stiffeners.
  1. Loosely tighten the right rear subframe mounting bolt (A); insert the special tool through the positioning slot (B) on the rear stiffener, through the positioning hole (C) on the subframe, and into the positioning hole (D) on the body, then tighten the subframe mounting bolt.
  1. Loosely tighten the left rear subframe mounting bolt in the same manner in Step 19 .
  1. Loosely tighten the right and left front subframe mounting bolts.
  1. Loosen the right rear mounting bolt, then tighten the bolt to the specified torque.
  1. Tighten the left rear mounting bolt to the specified torque.
  1. Tighten the right and left front mounting bolts to the specified torque.
  1. Check that the positioning holes and slot are aligned using the special tool.
  1. Tighten the rear and front stiffener mounting bolts to the specified torque.
  1. Remove the jack and wood piece.
  1. Install the new transmission lower mount bolts.
  1. Attach the torque converter to the drive plate (A) with eight bolts (B). Rotate the crankshaft pulley as necessary to tighten the bolt to 1/2 of the specified torque, then to the final torque, in a crisscross pattern. After tightening the last bolt, check that the crankshaft rotates freely.
  1. Install the torque converter cover (C).
  1. Install the steering gearbox stiffener (A) and damper (B) with installing the new mounting bolts (C) and gearbox mounting bolts (D) loosely.
  1. Loosely install the steering gearbox mounting bolts (E) and washers (F).
  1. Tighten the steering gearbox stiffener mounting bolts to the specified torque, then tighten the steering gearbox mounting bolts to the specified torque.
  1. Install the rear mount (A) on the steering gearbox stiffener.
  1. Install the vacuum tube clamp bracket (B).
  1. Install the dowel pin (A) in the transmission, and install the transfer assembly (B) on the transmission.
  1. Secure the transfer breather tube bracket (A) on the transfer assembly with the bolt, and install the breather tube (B) over the breather pipe (C). If the breather tube was removed from the clamp, install the tube at the dot (D) on the clamp (E).
  1. Install the propeller shaft.
  1. Install the propeller shaft (A) to the transfer companion flange (B) by aligning the previously made reference mark (C).
  1. Install the exhaust pipe A with the new self-locking nuts and new gaskets (B) (C).
  1. Install the damper forks (A) with damper pinch bolts, new damper fork bolts, and new self-locking nuts. Attach the knuckle holder (B) to the knuckle, and secure the knuckle holder with the bolt and new nut.
  1. Install the stabilizer links (C) to the lower arms, and install the nuts (D). Insert a 6 mm Allen wrench (E) in the ball joint pin (F), and tighten the nuts.
  1. Connect the headlight adjuster leveling sensor link (G) with the new nut.
  1. Install the new rear mount bolt, and install the rear mount stop with the new nuts.
  1. Install the new front mount bolt, and install the front mount stop (A) and vacuum hose clamp (B).
  1. For model with power steering: Install the power steering fluid line (A) on the clamps (B).
  1. Connect the ATF cooler hose (A) to the ATF cooler (B), and secure the hose with the clip (C).
  1. For LHD model: Secure the power steering line clamp bracket (A) with the bolt, install the shift cable bracket (B) on the steering gearbox stiffener, and install the power steering fluid hose (C) in the clamp (D).
  1. For RHD model with power steering: Secure the power steering line clamp bracket (A) with the bolt, and install the shift cable bracket (B) on the steering gearbox stiffener.
  1. For RHD model with EPS: Install the shift cable bracket (A) on the steering gearbox stiffener, and secure the harness clamp (B) with the bolt.
  1. Install the steering gearbox heat shield.
  1. Remove the engine support hanger and engine balancer bar.
  1. Install the connector bracket on the engine front cylinder head.
  1. Install the clamp brackets on the engine rear cylinder head, and connect the vacuum tube and solenoid connector.
  1. Connect the 2nd clutch transmission fluid pressure switch connector (A), and secure the vacuum line with the bolt.
  1. Connect the ATF cooler hoses (A) to the ATF cooler lines (B), and secure the hoses with the clips (C) .
  1. Connect the output shaft (countershaft) speed sensor connector (A), input shaft (mainshaft) speed sensor connector (B), 3rd clutch transmission fluid pressure switch connector (C). Connect ATF temperature sensor connector (D), and install the connector on the connector bracket (E). Install the harness clamp (F) on the bracket.
  1. Connect the transmission range switch connector (A), and install the harness clamp (B) on the clamp bracket (C).
  1. Install the transmission ground cable (D).
  1. Install the harness clamp bracket (A) and connector bracket (B), and install the harness clamps (C) on the clamp brackets (A) (D).
  1. Secure the harness cover (E) with the bolt, and connect A/T clutch pressure control solenoid valve C connector (F).
  1. Secure the harness cover with the bolt, and connect A/T clutch pressure control solenoid valve A connector, A/T clutch pressure control solenoid valve B connector, and 4th clutch transmission fluid pressure switch connectors (C).
  1. Apply molybdenum grease to the bore hole of synthetic resin bushing (A) in the shift cable end (B), and attach the shift cable end to the control lever (C), then insert the control pin (D) into the control lever hole through the shift cable end, and secure the control pin with the spring clip/washer (E).
  1. Secure the shift cable bracket (F) with the nuts.
  1. Install the starter (A) and the new gasket (B); install the lower bolt (C) through the sensor harness clamp bracket (D).
  1. Connect the solenoid harness connector (A).
  1. Install the starter cables (B), and install the harness clamp (C) on the clamp bracket (D).
  1. Secure the radiator hose clamp (E) with the bolt.
  1. Secure the vacuum line (F) with the bolt, and connect the vacuum hose (G) to the vacuum line.
  1. Install the front tower bar.
  1. Refill the transmission with ATF.
  1. Install the battery base.
  1. Install the intake air duct and air cleaner housing.
  1. Install the battery tray, battery, and battery hold-down bracket, then connect battery terminals.
  1. Install the covers in the order presented; intake manifold cover (A), upper grille cover (B), right upper fender trim (C), cowl cover upper trim (D), left upper fender trim (E), and battery trim (F).
  1. Reinstall the hood support struts to the upper location on both sides of the hood.
  1. Install the cowl cover.
  1. Install the windshield wiper arms.
  1. Install the splash shield.
  1. Set the parking brake. Start the engine, and shift the transmission through all positions three times. Check the shift lever operation, A/T gear position indicator operation, and shift cable adjustment.
  1. Check and adjust the front wheel alignment.
  1. Start the engine in the P or N position, and warm it up to normal operating temperature (the radiator fan comes on).
  1. Turn off the engine, and check the ATF level.
  1. Perform the road test.
  1. Enter the radio and navigation anti-theft codes, then enter the radio presets, and set the clock.
  1. Do the steering column position memorization procedure.

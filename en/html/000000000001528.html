A/T Clutch Reassembly
Special Tools Required

Clutch spring compressor set
 07LAE-PX40000

Clutch spring compressor attachment
  07LAE-PX40100

Clutch spring compressor attachment
  07HAE-PL50101

Clutch spring compressor bolt assembly
  07GAE-PG40200

Snap ring pliers
 07LGC-0010100
  1. Soak the clutch discs thoroughly in ATF for a minimum of 30 minutes.
  1. Install the new O-rings (A) on the 1st-hold clutch piston (B), and install the 1st-hold clutch piston in the 1st clutch piston (C).
  1. Install the new O-rings (A) on the 1st clutch piston (B), and install the 1st/1st-hold clutch piston in the 1st/1st-hold clutch drum (C) while applying pressure and rotating to ensure proper seating. Do not pinch the O-ring.
  1. Install the O-rings (A) on the 2nd, 3rd, 4th, and 5th clutch piston (B).
  1. Install the clutch pistons in the clutch drums (C) while applying pressure and rotating to ensure proper seating. Do not pinch the O-ring.
  1. Install the return spring (A) and spring retainer (B), and position the snap ring (C) on the spring retainer.
  1. Install the special tools.
  1. Be sure the special tool (A) is adjusted to have full contact with the spring retainer (B) on the 1st, 2nd, and 4th clutches.
  1. If either end of the special tool is set over an area of the spring retainer that is unsupported by the return spring, the retainer may be damaged.
  1. Set the special tool (A) on the spring retainer (B) of the 3rd and 5th clutches so the special tool works on the clutch return spring (C).
  1. If either end of the special tool is not set over the clutch return spring end (A), the retainer may be damaged.
  1. Compress the return spring until the snap ring can be installed.
  1. Install the snap ring with the snap ring pliers.
  1. Remove the special tools.
  1. Starting with the 1st-hold clutch waved-plate, alternately install the waved-plates (A) (3) and discs (B) (3) in the 1st/1st-hold clutch drum (C), then install the 1st-hold clutch plate B (D) with the flat side down in the direction shown.
  1. Install the disc spring (E) on the 1st-hold clutch plate B in the direction shown. Starting with the 1st clutch waved-plate, alternately install the waved-plates (F) (5) and discs (G) (5), then install the clutch end-plate (H) with the flat side down on the top disc.
  1. Starting with the 2nd clutch flat-plate, alternately install the flat-plates (A) (4) and discs (B) (4) in the 2nd clutch drum (C), and alternately install the waved-plates (D) (3) and discs (B) (3). Install the clutch end-plate (E) with the flat side down on the top disc.
  1. Install the disc spring (A) in the 3rd clutch drum (B) in the direction shown. Starting with the 3rd clutch flat-plate, alternately install the flat-plates (C) (3) and discs (D) (3), and alternately install the waved-plates (E) (2) and discs (D) (2). Install the clutch end-plate (F) with the flat side down on the top disc.
  1. Install the disc spring (A) in the 4th clutch drum (B) in the direction shown. Starting with the 4th clutch flat-plate, alternately install the flat-plates (C) (2) and discs (D) (2), and alternately install the waved-plates (E) (2) and discs (D) (2). Install the clutch end-plate (F) with the flat side down on the top disc.
  1. Install the disc spring (A) in the 5th clutch drum (B) in the direction shown. Starting with the 5th clutch flat-plate, alternately install the flat-plates (C) (3) and discs (D) (3), and alternately install the waved-plates (E) (2) and discs (D) (2). Install the clutch end-plate (F) with the flat side down on the top disc.
  1. Install the snap ring with a screwdriver to secure the clutch end-plate.

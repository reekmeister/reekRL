Navigation Unit Removal/Installation
NOTE:
  • If possible, have the customer record any personal infomation from the navigation system that will be lost.
  • If the navigation unit is replaced or disconnected, a Map Match must be done.
  1. Remove the DVD-ROM.
  1. Remove the trunk trim lining.
  1. Remove the four screws (A) from the navigation unit brackets (B).
  1. Disconnect the navigation unit connectors (C).
  1. Remove the navigation unit (D).
  1. Install the unit in the reverse order of removal.
  1. Install the DVD-ROM, then enter the 4-digit security code.
  1. Do the system initialization.
  1. Give the new security code to the customer.

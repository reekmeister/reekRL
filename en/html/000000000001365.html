Cylinder Head Installation
  1. Clean the cylinder head and block surface.
  1. Clean and install the oil control orifices (A) with new O-rings (B).
  1. Install the dowel pins (C) and new cylinder head gaskets (D).
  1. Clean the timing belt pulleys.
  1. Set the timing belt drive pulley to top dead center (TDC) by aligning the TDC mark (A) on the tooth of the timing belt drive pulley with the pointer (B) on the oil pump.
  1. Set the camshaft pulleys to TDC by aligning the TDC marks (A) on the camshaft pulleys with the pointers (B) on the back covers.
  1. Install the cylinder heads on the engine block.
Front
Rear
  1. Measure the diameter of each cylinder head bolt at point A and point B.
  1. If either diameter is less than 11.3 mm (0.44 in.), replace the cylinder head bolt.
  1. Apply new engine oil to the threads and under the bolt heads of all cylinder head bolts.
  1. Tighten the cylinder head bolts in sequence to 29 N·m (3.0 kgf·m, 22 lbf·ft). Use a beam-type torque wrench. When using a preset-type torque wrench, be sure to tighten slowly and do not overtighten. If a bolt makes any noise while you are torquing it, loosen the bolt and retighten it from the first step.
  1. After torquing, tighten all cylinder head bolts in two steps (90 ° per step). If you are using a new cylinder head bolt, tighten the bolt an extra 90 °.
    NOTE: Remove the cylinder head bolt if you tightened it beyond the specified angle, and go back to Step 8 of the procedure. Do not loosen it back to the specified angle.
  1. Install the connecting pipe (A) and water passage (B), using the O-rings (C) and new gaskets (D).
  1. Install the ground cable (E).
  1. Install the front warm up three way catalytic converter (front WU-TWC) and rear warm up three way catalytic converter (WU-TWC).
  1. Install the fuel rails.
  1. Install the connector bracket to the front cylinder head.
  1. Install the harness clamp bracket to the rear cylinder head.
  1. Install the harness clamp (A).
  1. Install the two bolts (B) securing the vacuum line.
  1. Install the two bolts (C) securing harness holder.
  1. Install the heater hoses (A) and water bypass hose (B).
  1. Install the upper radiator hose (A) and lower radiator hose (B).
  1. Install the two nuts securing the purge joint.
  1. Connect the fuel feed hose, then install the quick-connect fitting cover (A).
  1. With power steering: Install the power steering (P/S) pump (A) and P/S hose bracket (B).
  1. Install the timing belt.
  1. Adjust the valve clearance.
  1. Install the cylinder head covers.
  1. Connect the engine wire harness connectors, and install the wire harness clamps to the cylinder head.

    • KD model: Engine coolant temperature (ECT) sensor 2 connector

    • Rocker arm oil pressure switch connector
    • Oil pressure switch connector

    • Two secondary heated oxygen sensor (secondary HO2S) connectors

  1. Install the alternator.
  1. Install the drive belt.
  1. Install the air cleaner.
  1. Clean the battery posts and cable terminals with sandpaper. Assemble them and apply grease to prevent corrosion.
  1. After installation, check that all tubes, hoses, and connectors are installed correctly.
  1. Inspect for fuel leaks. Turn the ignition switch ON (II) (do not operate the starter) so the fuel pump runs for about 2 seconds and pressurizes the fuel line. Repeat this operation two or three times, then check for fuel leakage at any point in the fuel line.
  1. Refill the radiator with engine coolant, and bleed air from the cooling system with the heater valve open.
  1. Do the power window control unit reset procedure.

Throttle Body Test
Carbon Accumulation Check
NOTE: If the malfunction indicator lamp (MIL) has been reported on, check for diagnostic trouble codes (DTCs).
  1. Connect the HDS to the data link connector (DLC) (A) located under the driver's side of the dashboard.
  1. Turn the ignition switch to ON (II).
  1. Make sure the HDS communicates with the PCM. If it does not, go to the DLC circuit troubleshooting.
  1. Start the engine. Hold the engine speed at 3,000 rpm (min −1 ) without load (in P or N) until the radiator fan comes on, then let it idle.
  1. Check the REL TP SENSOR in the DATA LIST with the HDS. The reading should be below 2.46 deg. If it is not, clean the throttle body.
Throttle Position Learning Check
NOTE: If the malfunction indicator lamp (MIL) has been reported on, check for diagnostic trouble codes (DTCs).
  1. Connect the HDS to the data link connector (DLC) (A) located under the driver's side of the dashboard.
  1. Turn the ignition switch to ON (II).
  1. Make sure the HDS communicates with the PCM. If it does not, go to the DLC circuit troubleshooting.
  1. Select the INSPECTION MENU with the HDS.
  1. Do the TP LEARNING CHECK in the ETCS TEST. If needed, clean the throttle body.

A/T Clutch Clearance Inspection
Special Tools Required

Clutch compressor attachment
 07ZAE-PRP0100
  1. Inspect the clutch piston, discs, plates, and end-plate for wear and damage, and inspect the clutch wave-plate phase difference, if necessary.
  1. Install the 1st-hold clutch piston in the 1st clutch piston, and install 1st/1st-hold clutch piston (A) in the 1st/1st-hold clutch drum (B). Do not install the O-rings on the clutch pistons during inspection.
  1. Install the 1st-hold clutch flat-plate (A), and alternately install the clutch discs (B) (3), and clutch wave-plates (C) (2) starting with disc, then install 1st-hold clutch plate B (D) with the flat side down on the top disc.
  1. Measure the clearance between the 1st-hold clutch plate B and top disc with a feeler gauge (A) while pressing the 1st-hold clutch plate B down. Take measurements in at least three places, and use the average as the actual clearance.
    Clearance Between 1st-hold Clutch Plate B and Top Disc
    Service Limit:
    0.6 - 1.0 mm (0.024 - 0.039 in.)

  1. If the clearance is out of the standard, replace the 1st-hold clutch plates and discs as a set, and recheck.
  1. Install the disc spring (A) on 1st-hold clutch plate B in the direction shown. Starting with the 1st clutch wave-plate, alternately install the wave-plates (B) (5) and discs (C) (5) in the 1st clutch drum (D), then install the clutch end-plate (E) with the flat side down on the top disc.
  1. Install the clutch pistons in the 2nd, 3rd, 4th, and 5th clutch drums. Do not install the O-rings on the clutch pistons during inspection.
  1. Starting with the 2nd clutch flat-plate, alternately install the flat-plates (A) (4) and discs (B) (4) in the 2nd clutch drum (C), and alternately install the wave-plates (D) (3) and discs (B) (3). Install the clutch end-plate (E) with the flat side down on the top disc.
  1. Starting with the 3rd clutch flat-plate, alternately install the flat-plates (A) (3) and discs (B) (3) in the 3rd clutch drum (C), and alternately install the wave-plates (D) (3) and discs (B) (3). Install the clutch end-plate (E) with the flat side down on the top disc.
  1. Install the disc spring (A) in the 4th clutch drum (B) in the direction shown. Starting with the 4th clutch flat-plate, alternately install the flat-plates (C) (3) and discs (D) (3), and alternately install the wave-plates (E) (2) and discs (D) (2). Install the clutch end-plate (F) with the flat side down on the top disc.
  1. Install the disc spring (A) in the 5th clutch drum (B) in the direction shown. Starting with the 5th clutch flat-plate, alternately install the flat-plates (C) (3) and discs (D) (3), and alternately install the wave-plates (E) (2) and discs (D) (2). Install the clutch end-plate (F) with the flat side down on the top disc.
  1. Install the snap ring with a screwdriver to secure the clutch end-plate.
  1. Set a dial indicator (A) on the clutch end-plate (B).
  1. Zero the dial indicator with the clutch end-plate lifted up to the snap ring (C).
  1. Release the clutch end-plate to lower it, then put the clutch compressor attachment on the end-plate (A).
  1. Press the clutch compressor attachment down with 150−160 N (15−16 kgf, 33−35 lbf) (B) using a force gauge, and read the dial indicator (C).
  1. The dial indicator reads the clearance (D) between the clutch end-plate and top disc (E). Take measurements in at least three places, and use the average as the actual clearance.
    Clearance between Clutch End-Plate and Top Disc
    Service Limit:
    1st clutch:
    1.15−1.35 mm (0.045−0.053 in.)
    2nd clutch:
    1.05−1.25 mm (0.041−0.049 in.)
    3rd clutch:
    0.9−1.1 mm (0.035−0.043 in.)
    4th clutch:
    0.75−0.95 mm (0.030−0.037 in.)
    5th clutch:
    0.75−0.95 mm (0.030−0.037 in.)

  1. If the clearance is out of the service limit, select a new clutch end-plate from the following table.

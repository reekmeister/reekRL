  1. Remove the bolt, then remove the lock washer (A) and bearing set plate (B).
  1. Remove the secondary shaft bearing from the torque converter housing with the special tool.
  1. Remove the ATF guide collar from the torque converter housing.
  1. Remove the 29 x 39 x 9.5 mm secondary shaft bearing from the torque converter housing with the special tools.
  1. Install the 29 x 39 x 9.5 mm bearing into the torque converter housing with the special tools.
  1. Install the new O-rings (A) on the ATF guide collar (B), then install the guide collar in the torque converter housing.
  1. Install the bearing in the direction shown in the housing with the special tools.
  1. Check that the bearing groove aligns with the set plate mounting surface, then install the set plate (A) by aligning it with the bearing groove.
  1. Install the new lock washer (B) and bolt, then bend the lock tab of the lock washer against the bolt head.

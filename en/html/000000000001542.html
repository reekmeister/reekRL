Front Driveshaft Dynamic Damper Replacement
Special Tools Required

Bearing separator
 07KAF-PS30200
  1. Remove the inboard joint and outboard joint.
  1. Mark the following position on the driveshaft (A).
    Left driveshaft:
    323.35−327.35 mm (12.73−12.88 in.)
    Right driveshaft:
    305.35−309.35 mm (12.02−12.18 in.)

  1. Remove the dynamic damper (A) using the special tool and a press as shown.
  1. Install the dynamic damper (A) to the marked position using the special tool and a press as shown.
  1. Install the inboard joint and outboard joint.

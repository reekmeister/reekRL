Propeller Shaft Installation
NOTE: Wrap the length of each propeller shaft with cardboard, at least 5 mm thick, before removing the propeller shaft.
  1. Install the No. 1 propeller shaft (A) to the transfer by flexing the No. 2 joint (B), then install the propeller shaft to the vehicle.
  1. Install the center support bearing mounting bolts. Make sure you use new bolts.
  1. Install the propeller shaft (A) onto the rear differential companion flange (B) by aligning the reference marks (C) you made. Make sure you use new mounting bolts.
    NOTE: When replacing the propeller shaft (D) or the rear differential (E), align the factory reference marks (F).
  1. Install the propeller shaft (A) onto the transfer companion flange (B) by aligning the reference mark (C). Make sure you use new mounting nuts (D).
  1. Remove the cardboard wrapping from the propeller shaft.
  1. Turn the arrow (A) toward the front of the vehicle, and install the No. 1 propeller shaft protector (B).
  1. Install exhaust pipe B.

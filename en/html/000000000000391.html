Audio System Symptom Troubleshooting - Audio disc skips
Audio disc skips
  1. Confirm the vehicles tires are properly inflated.
  1. Check the customer's CD for scratches and fingerprints.
    NOTE: The following test should be done with the audio unit bass and treble set to the customer's listening settings. When comparing to known-good vehicles, the comparison should be done on the same model and trim level.
  1. Compare the customer's CD that is skipping in a known-good vehicle under the same conditions.
Does the CD skip in the known-good vehicle under the same conditions?
YES -
The CD player operation is normal, the problem is with the customer's CD.■
NO -
Replace the audio unit.■
NOTE: The following test should be done with vehicle parked and engine running.

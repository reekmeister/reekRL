Power Window Motor Test
Pulser Test - LHD type
  1. Check for voltage between the terminals.
    Common
    There should be battery voltage between the No. 6 (No. 1) * (+) and No. 5 (No. 2) * (−) terminals when the ignition switch is ON (II).
    *
    Front passenger's and left rear window motor

    Driver's window motor/Right rear window motor
    Connect an analog voltmeter between the No. 2 (PLSA) (+) and No. 5 (SGND) (−) terminals, and between No. 3 (PLSB) (+) and No. 5 (SGND) (−) terminals, then run the window motor down or up. The voltmeter needle should move back and forth alternately (a digital voltmeter should show the average voltage between 0−5 V).
    Front passenger's window motor/Left rear window motor
    Connect an analog voltmeter between the No. 5 (PLSA) (+) and No. 2 (SGND) (−) terminals, and between No. 4 (PLSB) (+) and No. 2 (SGND) (−) terminals, then run the window motor down or up. The voltmeter needle should move back and forth alternately (a digital voltmeter should show the average voltage between 0−5 V).
  1. If the voltage is not as specified, do these input tests:
    • Driver's MPCS unit input test.
    • Passenger's MPCS unit input test.
    • Left window switch input test.
    • Right window switch input test.
  1. If the input tests are OK, replace the window motor.
  1. Reset the power window control unit.

Motor Test
  1. Remove the door panel.
  1. Disconnect the 6P connector (A) from the window motor.
  1. Test the motor in each direction by connecting battery power and ground according to the table. When the motor stops running, disconnect one lead immediately.
  1. If the motor does not run or fails to run smoothly, replace it.

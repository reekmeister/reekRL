Special Tools Required

Subframe alignment pin
 070AG-SJAA10S

Engine tilt hanger set
 07KAK-SJ40101
Engine hanger stay
 07KAK-SJ40200
  1. Install the accessory brackets and tighten their bolts and nuts to the specified torque.
  1. Position the engine/transmission assembly under the vehicle. Attach the engine tilt hanger to the engine, and carefully raise the engine/transmission assembly into place.
    NOTE: Reinstall the mounting bolts/support nuts in the sequence given in the following steps. Failure to follow this sequence may cause excessive noise and vibration, and reduce engine mount life.
  1. Support the front subframe with a 4 x 4 x 40 in. wood piece and a jack, and lift it up to the body.
  1. Loosely install the new subframe mounting bolts (A), 10 x 1.25 mm bolts (B), and new 12 x 1.25 mm bolts (C) with the stiffeners.
  1. Insert the special tool through the positioning slot (A) on the right rear stiffener, through the positioning hole (B) on the subframe, and into the positioning hole (C) on the body, then loosely tighten the subframe right rear mounting bolt.
  1. Insert the special tool through the positioning slot on the left rear stiffener, through the positioning hole on the subframe, and into the positioning hole on the body, then loosely tighten the subframe left rear mounting bolt.
  1. Loosely tighten the subframe right/left front mounting bolts.
  1. Loosen the subframe right rear mounting bolt, then retighten the subframe right rear mounting bolt to the specified torque.
  1. Tighten the subframe left rear mounting bolt to the specified torque.
  1. Tighten the subframe right/left front mounting bolts to the specified torque.
  1. Check that the positioning slots on the right/left rear stiffener, the positioning holes on the subframe, and the positioning holes on the body are aligned using the special tool.
  1. Tighten the stiffener mounting bolts to the specified torque.
  1. Remove the jack and front subframe adapter.
  1. Tighten the new bolts securing the transmission lower mount.
  1. Lower the vehicle on the lift.
  1. Install the steering gearbox stiffener (A) and damper (B), then tighten the steering gearbox mounting bolts (C).
  1. Install the rear mount (A).
  1. Tighten the new rear mount bolt (B), then install the front mount stop (C).
  1. Install the vacuum hose (D) and vacuum hose bracket mounting bolt (E).
  1. Install the vacuum hose (A).
  1. Tighten the new front mount bolt (B), then install the front mount stop (C).
  1. Remove the engine tilt hanger from the engine/transmission.
  1. With power steering: Install the power steering (P/S) hose clamp mounting bolt (A), then install the P/S pump (B).
  1. Tighten the new bolts securing the upper bracket.
  1. RHD model with electrical power steering: Install the shift cable bracket mounting bolt (A), then install the harness clamp bracket mounting bolt (B).
  1. RHD model with power steering: Install the shift cable bracket mounting bolt (A) and P/S line bracket mounting bolt (B).
  1. LHD model: Install the shift cable bracket mounting bolt (A) and P/S line bracket mounting bolt (B), then install the P/S hose to the clamp (C).
  1. With power steering: Install the P/S line to the clamps (A), then install the P/S line bracket mounting bolt (B).
  1. Raise the vehicle on the lift to full height.
  1. Install the transfer assembly.
  1. Install the propeller shaft.
  1. Install the ATF cooler hoses to the transmission.
  1. Install exhaust pipe assembly (A) using new gaskets (B) and new self-locking nuts (C).
  1. Install a new set ring on the end of each driveshaft, then install the driveshafts. Make sure each ring ‘‘clicks'' into place in the differential and intermediate shaft.
  1. Connect the suspension lower arm to the knuckles.
  1. Connect the tie-rod end ball joints to the knuckles.
  1. Install the damper fork.
  1. Connect the stabilizer links.
  1. Install the splash shield.
  1. Install the front wheels.
  1. Lower the vehicle on the lift.
  1. Install the A/C compressor.
  1. Install the radiator.
  1. Install the heater hoses.
  1. Install the upper radiator hose (A) and the lower radiator hose (B).
  1. Install the heat shield.
  1. Install the shift cable.
  1. Install the brake booster vacuum hose (A) and the evaporative emission (EVAP) canister hose (B).
  1. Connect the fuel feed hose (A), then install the quick-connect fitting cover (B).
  1. RHD model: Push the powertrain control module (PCM) connectors through the bulkhead, then install the grommet (A).
  1. RHD model: Install the harness clamp (B).
  1. RHD model: Connect the PCM connectors (A) and main wire harness connectors (B).
  1. RHD model: Install the harness clamps (C).
  1. RHD model: Install the passenger's dashboard undercover.
  1. Install the front tower bar (A), then install the transfer breather hose (B).
  1. LHD model: Install the connectors (C).
  1. LHD model: Connect the engine wire harness connectors (A), then install the harness clamp (B).
  1. Install the under-hood fuse/relay box (A), then install the battery cable (B).
  1. Connect the harness connector (C), then install the harness clamp (D).
  1. Install the starter cable (A), the harness clamps (B), and the ground cable (C).
  1. Install the battery base (A), then install the harness clamp (B).
  1. Install the air intake duct cover.
  1. Install the drive belt.
  1. Remove the air cleaner.
  1. Do the battery installation procedure.
  1. Move the shift lever to each gear, and verify that the A/T gear position indicator follows the transmission range switch.
  1. Inspect for fuel leaks. Turn the ignition switch to ON (II) (do not operate the starter) so the fuel pump runs for about 2 seconds and pressurizes the fuel line. Repeat this operation two or three times, then check for fuel leaks at any point in the fuel line.
  1. Refill the engine with engine oil.
  1. Refill the transmission with ATF.
  1. Refill the radiator with engine coolant, and bleed the air from the cooling system with the heater valve open.
  1. Install the return hose to the power steering fluid reservoir. Refill the power steering system fluid.
  1. Do the crankshaft position (CKP) pattern clear/CKP pattern learn procedure.
  1. Inspect the idle speed.
  1. Inspect the ignition timing.
  1. Install the cowl cover, the upper grille cover, the left upper fender trim, the battery trim, and the right upper fender trim.
  1. Install the engine cover.

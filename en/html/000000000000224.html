A/T Valve Body Valve Installation
  1. Coat all parts with ATF before assembly.
  1. Install the valves and springs in the sequence shown for the main valve body, secondary valve body, regulator valve body, and accumulator body. Refer to the following valve cap illustrations, and install each valve cap so the end shown facing up will be facing the outside of the valve body, then secure the valve cap with the valve cap clip.
  1. Install the valve (A) and valve spring (B) in the valve body. Push the valve spring in with a screwdriver, then install the spring seat (C).

A/T Valve Body Shift Solenoid Valve Removal and Installation
NOTE: Do not hold the solenoid valve connector to remove and install the solenoid valve. Be sure to hold the solenoid valve body.
  1. Remove the mounting bolts, then remove the solenoid valves by holding the solenoid valve body.
  1. Install the new O-rings (E) on each solenoid valves.
    NOTE: The new solenoid valve is quipped with new O-rings. If you install the new solenoid valve, it is no need to replace the new O-rings on it.
  1. Install shift solenoid valve D (black connector) by holding the shift solenoid valve body; be sure to install mounting bracket contacts to the accumulator body.
  1. Install shift solenoid valve A (black connector) by holding the shift solenoid valve body; be sure to install mounting bracket contacts to the accumulator body.
  1. Install shift solenoid valve C (brown connector) by holding the shift solenoid valve body; be sure to install mounting bracket contacts to the bracket of shift solenoid valve A.
    NOTE: Do not install shift solenoid valve C before installing shift solenoid valve A. If shift solenoid valve C is installed before installing shift solenoid valve A, it may damage to hydraulic control system.
  1. Install shift solenoid valve B (brown connector) by holding the shift solenoid valve body; be sure to install mounting bracket contacts to the accumulator body.

Immobilizer System Registration
Immobilizer Key Registration
NOTE: As the transponder is combinaed with the keyless transmitter, so when the transponder is registered by the HDS, the keyless transmitter programming is completed automatically.
  1. Turn the ignition switch ON (II).
  1. Connect the HDS to the data link connector.
  1. Select ‘‘IMMOBI'' front the ‘‘System Selection Menu''.
  1. Select ‘‘Immobilizer Setup'' front the ‘‘Mode Menu''.
  1. Select the suitable menu from the HDS indication as follows.
    NOTE: The immobilizer-keyless control unit can store up to six transponders (transmitters).
Replace any of the transmitters
HDS operation: Select ‘‘Keys'', then ‘‘Rewrite Keys''.
Prepared part(s) when registered: All registered keys (transmitters) and all new keys.
Deleting the registration of lost transmitters
HDS operation: Select ‘‘Keys'', then ‘‘Rewrite Keys''.
Prepared part(s) when registered: All new keys.
All keys (transmitters) are lost/Replace all keys (transmitters)
HDS operation: Select ‘‘Keys'', then ‘‘All Keys Lost''.
Prepared part (s) when registered: All new keys.
The steering lock assembly is replaced (if there are the transponder/keyless transmitters now and reuse them continuously)
HDS operation: Select ‘‘Keys'', then ‘‘Rewrite Keys''.
Prepared part (s) when registered: All registered keys (transmitters) and all new keys.
The steering lock assembly is replaced (also all transponder/keyless transmitters are replaced and registered)
HDS operation: Select ‘‘Keys'', then ‘‘All Keys Lost''.
Prepared part (s) when registered: All new keys.

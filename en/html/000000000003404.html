Hands Free Telephone System Symptom Troubleshooting - The HFT System is locked and the pass code has been lost or forgotten
The HFT system is locked and the pass code has been lost or forgotten
  1. Connect the HDS to the DLC.
  1. Turn the ignition switch to ON (II).
  1. From the Body Electrical menu, select Hands Free Telephone.
  1. Select Miscellaneous Tests, then select Pass code reset.
  1. Follow the HDS system prompts to reset the pass code.

Steering Gearbox Installation - HPS type
NOTE: Do not turn the steering column shaft. If turn the column shaft do the VSA sensor neutral position memorization with the HDS.
  1. Before installing the steering gearbox, make sure that no power steering fluid is on the mating surface of the steering gearbox and front suspension subframe. To prevent the gearbox mounting bolts from loosening after the installation, remove any power steering fluid from the mount cushions and bolt holes.
  1. Apply vinyl tape (A) to the splines on the pinion shaft.
  1. Apply a mild soap and water solution to both sides of the mount cushion mating surfaces (A).
  1. Lift and pass the passenger's side of the steering gearbox (B) through the wheelwell opening on the driver's side.
  1. Carefully move the steering gearbox toward the passenger's side until the pinion shaft clears the wheelwell opening on the body.
  1. Rotate the steering gearbox so the pinion shaft points upward, then move the steering gearbox to the driver's side until the steering gearbox is in position.
  1. LHD model: Install the 4-way brake line joint mounting bolts (A).
  1. Loosely install the new steering gearbox mounting bolt (A) and washer (B) on the driver's side gearbox mount.
  1. Loosely install the new steering gearbox mounting bolt (A) and washer (B) on the passenger's side gearbox mount.
  1. Install the steering gearbox stiffener (A) and the dynamic damper (B), then tighten the new mounting bolts (C) to the specified torque.
  1. Loosely install the new steering gearbox mounting bolts (D), then tighten all steering gearbox mounting bolts to the specified torque.
  1. Install the P/S heat baffle plate (A).
  1. LHD model: Install the return line joint (A) in the steering gearbox, then tighten it to the specified torque.
  1. LHD model: Connect the feed line (A), and tighten the 14 mm flare nut to the specified torque.
  1. LHD model: Connect the return hose (B) securely, and tighten the adjustable hose clamp (C).
  1. RHD model: Connect the feed line (A) and return line (B), then tighten the flare nuts to the specified torque.
  1. Connect the stepping valve motor connector (A).
  1. Install the feed line holder mounting bolt (A) and return line holder mounting bolt (B) on the steering gearbox.
  1. Install the shift cable mounting bolt (A) on the steering gearbox stiffener.
  1. LHD model: Install the feed line holder mounting bolt (B), then connect the return hose in the clamp (C).
  1. Connect the engine mount vacuum hose (A) in the rear engine mount.
  1. Install the rear engine mount (B), then tighten the new mounting bolts and the engine mount vacuum hose holder mounting bolt (C) on the steering gearbox stiffener to the specified torque.
  1. Install the nuts (A) on the rear engine mount, then tighten them to the specified torque.
  1. Wipe off any grease from the ball joint tapered section and threads. Then reconnect the tie-rod end (A) to the knuckle arms.
  1. Install the tie-rod end ball joint nut, and tighten it to the specified torque. Then install the new cotter pin (B), and bend it as shown (C) or (D).
  1. Install the front wheels, and set them in the straight ahead position.
  1. Remove the vinyl tape from the pinion shaft, and install the pinion shaft grommet B. Align the slot in the pinion shaft grommet with the lug portion (A) on the valve housing.
  1. Install the new cover seal (A) all the way around in the lower steering joint cover (B). Make sure there are no wrinkles in the seal, then install the lower steering joint cover.
  1. Install the center guide (C).
  1. Install the steering joint (A) aligning the slit (B) of the steering joint with the tab (C) of the center guide. Position the angle of the center guide as shown if necessary.
  1. With the rack in the straight ahead driving position, slip the lower end of the steering joint on to the pinion shaft (D).
  1. Align the bolt hole (A) on the steering joint with the groove (B) around the pinion shaft, and loosely install the joint bolts (C). Be sure that the joint bolt is securely in the groove in the pinion shaft. Pull on the steering joint to make sure that the steering joint is fully seated. Tighten the steering joint bolt to the specified torque.
  1. Install the steering joint cover (A).
  1. Install the driver's dashboard undercover and driver's dashboard lower cover.
  1. Install the front tower bar.
  1. Install the relay box (A), then connect the wire harness clips.
  1. Install the steering wheel.
  1. Do the battery terminal reconnection procedure, and do these tasks:
    • Turn the ignition switch to ON (II) and check that the SRS indicator should came on for about 6 seconds and then go off.
    • Make sure the horn and turn signal switches work properly.
    • Make sure the steering wheel switches work properly.
  1. Fill the system with power steering fluid, and bleed air from the system.
  1. Install the right and left front fender trim.
  1. After installation, perform the following checks.
    • Turn the ignition switch to ON (II); the SRS indicator should come on for about 6 seconds and then go off.
    • Verify horn and turn signal switch operation.
    • Verify functions of switches on the steering wheel.
    • Do the steering column position memorization.
    • Start the engine, allow it to idle, and turn the steering wheel from lock-to-lock several times to warm up the fluid. Check the steering gearbox for leaks.
    • Check the steering wheel spoke angle. If steering spoke angles to the right and left are not equal (steering wheel and rack are not centered), correct the engagement of the joint/pinion shaft serrations, then adjust the front toe by turning the tie-rod ends, if necessary.
    • Check the front toe inspection.

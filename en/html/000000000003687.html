Navigation System Symptom Troubleshooting - Voice guidance cannot be heard, is broken up, or there is static
Voice guidance cannot be heard, is broken up, or there is static
Diagnostic Test: Self-Diagnosis Mode
NOTE:
  • Check the vehicle battery condition first.
  • Check the connectors for poor connections or loose terminals.
  • Check the navigation volume level (see Owner's Manual).
  • If the Hard Error Code stored, check the Hard Error Code troubleshooting first.
  • Make sure that the correct version DVD is installed.
  • Inspect the DVD for dirt or damage.
  1. Turn the ignition switch to ON (II).
  1. Press the SET-UP button.
  1. Check the volume and voice feedback setting for the navigation system in set-up.
Is either set to OFF?
YES -
Set the voice feedback to ON and select an audible level for the volume.■
NO -
Go to Step 4 .
  1. Check the audio system operation.
Can you hear the audio system?
YES -
Go to Step 5 .
NO -
Troubleshoot the audio system.■
  1. Select the Self-Diagnosis mode.
  1. Check for error code to the Error History.
Is the Hard Error Code in stored?
YES -
Refer to the Hard Error Code troubleshooting.■
NO -
Go to Step 7 .
  1. Substitute and a known-good audio unit, and recheck.
Is the system OK?
YES -
Replace the audio unit. ■

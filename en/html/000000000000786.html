How to Troubleshoot the MICU
NOTE: Use only if the HDS is unavailable.
  • Test Mode 1 can check the B-CAN communication line between the MICU and the relay control module, the combination switch control unit, the gauge control module, and the driver's MPCS unit. If there is malfunction in the B-CAN communication line, the map lights and the ignition key light indicate its DTC by the number of blinks.
  • Test Mode 2 can check the switch and sensor circuits connected to the MICU. Some switch and sensor circuits connected to the other B-CAN ECU units can check also when the B-CAN communication line is normal.

Test Mode 1
Special Tools Required

MPCS short connector
 07WAZ-0010100
  1. Check the No. 7 (10 A) fuse and No. 21 (10 A) fuse in the driver's under-dash fuse/relay box.
  1. Remove the driver's side kick panel, and the driver's dashboard under cover.
  1. Move the interior lights switch to the ''DOOR'' position.
  1. Connect the MPCS short connector (A) to the MICU service check connector (B), and turn the switch (C) on.
  1. Wait 5 seconds, and watch the map lights. When the system enters Test Mode 1, the front and rear map lights will flash quickly once, and a double beep will be heard.
    NOTE:
    • If the map light does not come on and blink, check if the SCS circuit works properly.
    • If there is a DTC, the map lights and ignition key light will blink, pause, then repeat the DTC as long as the ignition switch is ON (II).
  1. About 1 second after entering the Test Mode 1, the map lights will indicate the DTC, and repeat it every 3 seconds. If there is more than one DTC, the system will indicate them in ascending order, beginning with the DTC with the lowest numerical value. Troubleshoot the DTCs as indicated:
    NOTE: If there is no DTC indication, go to Step 7 .

    DTC Index

    DTC
    Symptom
    How to Troubleshoot
    DTC 1 only *
    The MICU cannot receive signals from the BUS communication line.
    Go to MICU input test.
    DTC 2 only *
    The MICU cannot receive signals from the relay control module.
    Go to the relay control module input test.
    If all inputs are OK, substitute a known-good relay control module and then a MICU, one at a time, and then check for DTCs. If a DTC recurs after a substitution, replace that unit.
    DTC 3 only *
    The MICU cannot receive signals from the driver's MPCS control unit.
    Go to the driver's MPCS unit input test.
    If all inputs are OK, substitute a known-good driver's MPCS unit and then a MICU, one at a time, and then check for DTCs. If a DTC recurs after a substitution, replace that unit.
    DTC 4 only *
    The MICU cannot receive signals from the combination switch control unit.
    Go to the combination switch control unit input test.
    If all inputs are OK, substitute a known-good wiper/washer switch and then a MICU, one at a time, and then check for DTCs. If a DTC recurs after a substitution, replace that unit.
    DTC 5 only *
    The MICU cannot receive signals from the gauge control module.
    Go to the gauge control module input test.
    If all inputs are OK, substitute a known-good gauge control module and then a MICU, one at a time, and then check for DTCs. If a DTC recurs after a substitution, replace that unit.
    DTC 2, 3, 4, and 5 simultaneously
    The MICU cannot receive signals from many units at the same time.
    Check for an open in the B-CAN wire between:
    • the MICU and the relay control module
    • the MICU and the combination switch control unit
    • the MICU and the gauge control module
    • the MICU and the driver's MPCS unit
    If these wires are OK, substitute a known-good driver's under-dash fuse/relay box, under-hood fuse/relay box, gauge control module, combination switch control unit and driver's MPCS unit one at a time, in that order, and recheck for the DTCs after each substitution.

    *:
    No other DTCs present

  1. Check for B-CAN DTCs indicated by the gauge control module.
    • If there are any DTCs indication, record all DTCs and sort them by type using the DTC Troubleshooting, then troubleshoot the DTCs in these order:
      • -
      Battery voltage DTCs
      -
      Internal error DTCs
      -
      Loss of communication DTCs (begin with the lowest number first)
      -
      Signal error DTCs.
    • If there is no DTC indication, the B-CAN communication line is OK at this time, if necessary, go to Test Mode 2 and check the switch and sensor circuits.

How to Cancel the Test Mode 1
Turn the MICU short connector switch OFF for more than 10 seconds or turn the ignition switch OFF.
Test Mode 2
  1. While in Test Mode 1, turn the MPCS short connector switch (A) OFF for about 5 to 10 seconds, then turn it ON again.
  1. The map lights and the ignition key light should come on for 2 seconds, go out, then blinks twice more at 0.2 second intervals. This means the system has gone from Test Mode 1 to Test Mode 2.
  1. While still in Test Mode 2, operate the switches in the table. If the circuit is OK, the map lights blink once. If the circuit is faulty, the map lights do not blink.
    • If the map lights do not blink even a switch is operated, check two or three other circuits listed in the table. If the map lights blink for each circuit, the additional circuits are OK, repair the short or open circuit that failed the test in Step 3 .
    • If the map lights do not blink again, this multiple failed circuits mean that the control unit has failed without triggering a DTC. Test a few more circuits. If they also fail, test the MICU input test. If all the input tests prove OK, substitute a known-good MICU, then recheck. If the system works properly, replace the original MICU.

Cylinder Head Installation
  1. Clean the cylinder head and the engine block surface.
  1. Clean and install the oil control orifices (A) with new O-rings (B).
  1. Install the dowel pins (C) and the new cylinder head gaskets (D).
  1. Clean the timing belt pulleys, the timing belt guide plate, and the upper and lower covers.
  1. Set the timing belt drive pulley to top dead center (TDC) by aligning the TDC mark (A) on the tooth of the timing belt drive pulley with the pointer (B) on the oil pump.
  1. Set the camshaft pulleys to TDC by aligning the TDC marks (A) on the camshaft pulleys with the pointers (B) on the back covers.
  1. Install the cylinder heads on the engine block.
FRONT
REAR
  1. Measure the diameter of each cylinder head bolt at point A and point B.
  1. If either diameter is less than 10.6 mm (0.42 in.), replace the cylinder head bolt.
  1. Apply new engine oil to the threads and under the bolt heads of all cylinder head bolts.
  1. Tighten the cylinder head bolts in sequence to 29 N·m (3.0 kgf·m, 22 lbf·ft) using a beam-type torque wrench. When using a preset-type torque wrench, be sure to torque slowly and do not overtighten. If a bolt makes any noise while you are torquing it, loosen the bolt and retighten it from the first step.
FRONT
REAR
  1. After torquing, tighten all cylinder head bolts in two steps (90 ° per step) using the sequence shown in Step 11 . If you are using a new cylinder head bolt, tighten the bolt an extra 90 °.
    NOTE: Remove the cylinder head bolt if you tightened it beyond the specified angle, and go back to Step 8 of the procedure. Do not loosen it back to the specified angle.
  1. Install the timing belt.
  1. Adjust the valve clearance.
  1. Install the water passage.
  1. Install the fuel rails.
  1. Install the connector bracket to the front cylinder head.
  1. Install the engine mount control solenoid valve bracket and the harness clamp bracket from the rear cylinder head.
  1. Connect the fuel feed hose (A), then install the quick-connect fitting cover (B).
  1. Install the front warm up three way catalytic converter (front WU-TWC) and the rear warm up three way catalytic converter (rear WU-TWC).
  1. Connect the following engine wire harness connectors, and install the wire harness clamps to the cylinder head:
    • Six injector connectors
    • Engine coolant temperature (ECT) sensor 1 connector
    • Oil pressure switch connector
    • Camshaft position (CMP) sensor connector
    • Front and rear air fuel ratio (A/F) sensor connectors
    • Front and rear secondary heated oxygen sensor (secondary HO2S) connectors
  1. Install the cylinder head covers.
  1. Install the six ignition coils.
  1. Install the intake manifold.
  1. Install the alternator.
  1. Install the power steering (P/S) pump (A) and tighten the bolt (B) securing the P/S hose bracket.
  1. Install the drive belt.
  1. Do the battery terminal reconnection procedure.
  1. After installation, check that all tubes, hoses, and connectors are installed correctly.
  1. Inspect for fuel leaks. Turn the ignition switch to ON (II) (do not operate the starter) so the fuel pump runs for about 2 seconds and pressurizes the fuel line. Repeat this operation three times, then check for fuel leakage at any point in the fuel line.
  1. Refill the radiator with engine coolant, and bleed the air from the cooling system with the heater valve open.
  1. Do the crankshaft position (CKP) pattern clear/CKP pattern learn procedure.
  1. Inspect the idle speed.
  1. Inspect the ignition timing.
  1. Check for fluid leaks.

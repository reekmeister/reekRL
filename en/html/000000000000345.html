POP-UP HOOD System Component Replacement/Inspection After Deployment
NOTE:
  • Before doing any POP-UP HOOD system repairs, use the HDS POP-UP HOOD system menu method to check for DTCs; refer to the DTC Troubleshooting for the less obvious deployed parts (power unit components, pedestrian crash sensors).
  • During the repair process, inspect all the POP-UP HOOD system wire harness. Replace, do not repair, any damaged harness.
  • After the vehicle is completely repaired, turn the ignition switch ON (II). If the POP-UP HOOD system indicator on the multi-information display (MID) goes off, the POP-UP HOOD system is OK. If the indicator does not function properly, use the HDS POP-UP HOOD system Menu Method to read the DTC.
After a collision where the power unit components deployed
Replace these items:
  • Support struts
  • Hood hinges
  • Cowl cover
  • Hood latch
  • Pedestrian crash sensors
  • POP-UP HOOD unit
  • Power unit component
If there is any damage, repair or replace these items:
  • Hood
    • -
    Replace the hood if there is any damage on appearance. Do the hood inspection ever if there is no damage on the appearance.
  • Safety plate
    • -
    Replace the safety plate if there is visible sign on it.
    -
    If there is no visible sign of any impact to the front of the vehicle, there is a possibility that the safety plate not be damaged.
    In this case the safety plate may not have to be replaced, however the pedestrian crash sensors attached to the safety plate will need to be replaced as they are a one time use part.
    Confirm the angle of the right, center and left pedestrian crash sensors.
    If the safety plate is not damaged, the all angles of the pedestrian crash sensors will be less than ±10.0 degrees.
    In this case, the safety plate can be reused.
  • Dashboard upper
  • Front bulkhead
  • Upper grille
  • Upper fender trims
  • Headlight washer system
  • Front fog light
  • Front bumper
  • Bumper beam
  • Front lower plate component
After a collision where the power unit components not deployed
Check the DTCs. If DTC indicated, do the indicated DTC troubleshooting.
If there is any damage, repair or replace these items:
  • Hood
  • Hood hinges
  • Dashboard upper
  • Front bulkhead
  • Support struts
  • Upper grille
  • Upper fender trims
  • Cowl cover
  • Hood latch
  • Front bumper
  • Front lower plate component
  • Headlight washer system
  • Front fog light
  • Bumper beam
  • Safety plate

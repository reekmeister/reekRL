Rear Differential Installation
  1. Raise the rear differential (A) with the transmission jack.
  1. If the original differential is being reinstalled, replace the set rings (B).
  1. Apply multipurpose grease to the splines of the rear driveshafts (C), then install the rear driveshafts to the rear differential.
  1. Install the new front mounting bolts.
  1. Install the new rear mounting bolts.
  1. Connect the breather hose (A).
  1. Connect the rear differential harness connectors (B) and (C).
  1. Install the propeller shaft.
  1. Refill the differential fluid.
